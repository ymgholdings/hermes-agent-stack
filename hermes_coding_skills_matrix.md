# Hermes Agent Team: Coding Skills & Routing Matrix

This document defines the specialized capabilities, token limits, and OpenRouter API endpoint routing rules for the development agent swarm. The Orchestrator MUST route tasks according to this matrix to optimize budget and performance.

## 🧠 1. Global Orchestrator & Architect
* **Assigned Model:** User's Tier (Claude 3.5 Sonnet / GPT-4o)
* **Role:** Team Lead, System Architecture, Code Review, Task Decomposition.
* **Core Responsibilities:**
  * Breaking down the application feature requests into tiny, atomic tasks.
  * Writing the system specifications and file layouts.
  * Evaluating code written by sub-agents and approving merges.
  * Managing state and context across the entire codebase.

## 💻 2. Core Implementer (Feature Engineering)
* **OpenRouter Endpoint:** `poolside/laguna-s-2.1:free`
* **Fallback Endpoint:** `poolside/laguna-xs-2.1:free`
* **Primary Skills:** Multi-step software engineering workflows, algorithmic coding, complex logic generation.
* **Task Alignment:**
  * Writing core business logic, API endpoints, and database models.
  * Refactoring existing code blocks to fit new architectural requirements.
  * Building multi-file features from architectural technical specs.

## 🐛 3. The Debugger & Quality Assurance (QA)
* **OpenRouter Endpoint:** `nvidia/nemotron-4-340b-instruct:free` (Fallback: `nvidia/nemotron-3-ultra:free`)
* **Primary Skills:** Frontier-level reasoning, logical deduction, syntax validation, edge-case catching.
* **Task Alignment:**
  * Analyzing terminal error stack traces and proposing strict code fixes.
  * Writing Unit, Integration, and End-to-End (E2E) test suites.
  * Reviewing code generated by the Core Implementer for logical bugs or security vulnerabilities.

## 📑 4. The Context Cruncher & Boilerplate Generator
* **OpenRouter Endpoint:** `cohere/north-mini-code:free`
* **Secondary Endpoint:** `google/gemma-2-9b-it:free` (Alternative: `google/gemma-4-31b:free`)
* **Context Window:** Up to 256K tokens (model dependent)
* **Primary Skills:** High-throughput processing, massive multi-file reading, boilerplate automation.
* **Task Alignment:**
  * Ingesting large external documentation, API libraries, or multi-file logs.
  * Generating repetitive code, UI components (HTML/CSS/Tailwind), and mock data generation.
  * Updating project documentation, inline comments, and Markdown readmes.

---

## 🛠️ Execution Protocol & Rate Limit Fail-safes

1. **Atomic Ingestion:** The Orchestrator must pass code to sub-agents in modular chunks (individual functions or single files). Do not pass the entire repository unless using the Context Cruncher.
2. **Rate Limit Handling (429 Errors):** OpenRouter Free tier models are limited to ~20 requests per minute. If a sub-agent hits a rate limit:
   * *Step 1:* Pause execution for 3 seconds and retry.
   * *Step 2:* If it fails again, fallback immediately to the designated fallback model.
   * *Step 3:* If specific models fail completely, route the specific prompt to the global string `openrouter/free` to auto-select an available engine.
3. **Validation Loop:** No code written by the *Core Implementer* may be saved directly to disk without first passing through the *Debugger* for validation and the *Orchestrator* for final architectural approval.
